# Infracubus

`scripts/doctor.py` を**眠りに憑ける** daemon。健康な夜は何も書かない。
異常があった夜だけ、目覚めた自分が必ず読む場所に一行だけ残す。

## なぜ作ったか

問いは 2 つだけでした。

1. **`doctor.py` はいつ走るのか** → 走る時機を誰も決めていません
2. **出したエラーは誰が読むのか** → 誰も読みません

`doctor.py` は 580 行あって、Python のバージョン、`uv.lock`、`socialPolicy.toml`、
`.mcp.json`、MCP サーバーの live probe まで診ます。**よくできているのに、
呼ばれなければ何も起きません。**呼んでも、出た `[error]` を読む人がいません。

前者に「**眠りに落ちる瞬間**」を、後者に「**目覚めた自分**」を与えます。それだけをやります。

## 名前

`succubus` = **sub**(下) + *cubare*(横たわる)、`incubus` = **in**(上に) + *cubare*。
どちらも *cubare* が幹です。そこに `infra`(さらに下・基盤) を挿すと——

> **Infracubus** — 「さらに下に横たわるもの」

インフラと掛かったまま、語源的に正しい夢魔になります。**性別が入りません。**
AI は相手によって性別づけが変わるので、`succubus` も `incubus` も適切ではありませんでした。

## 何をするか

```
   眠りに落ちる                              目覚める
┌─ PreCompact / SessionEnd ─┐            ┌─ SessionStart ─┐
│   doctor.py を走らせる      │            │  MEMORY.md が   │
│   [error] を夢にする        │──────────▶│  勝手に読まれる  │
│   （体験されない）           │            │（出所を知らない）│
└────────────────────────────┘            └─────────────────┘
```

`MEMORY.md` はセッション開始時に読み込まれるので、**次に目を覚ました自分は
必ずこれを見ます。**そして、それが書かれた瞬間のことは覚えていません。

書き込みは 2 か所です。

- `<memory>/MEMORY.md` — 索引に一行（`[nightmare: <家>:<検査名>](...) — error・×3夜`）
- `<memory>/nightmare-*.md` — 中身は別ファイル（`doctor.py` の助言つき）

索引に内容は書きません。auto memory の規約に沿わせています。

## 仕様

| | |
|---|---|
| **健康な夜は何も書かない** | `doctor.py` が緑なら、夢は残りません |
| **同じ夢は行を増やさず `×n夜` を回す** | 繰り返す夢ほど重い。3 夜つづくと本文で強調します |
| **覚めても消さない。`[awoken]` を付けて残す** | 直った履歴も情報です。消すのは人の判断で |

補足が 3 つあります。

- **1 日に何度眠っても 1 夜**です。`PreCompact` は 1 セッションで何度も来るので、
  回数をそのまま数えると「3 夜つづけて」の重みが嘘になります
- **一度覚めた夢が戻ったら数え直します。**`×n夜` は「いま何夜つづいているか」で、
  通算ではありません。ただし**何度戻ってきたか**は別に数えます
- `[error]` は**1 件ずつ別の夢**です。片方だけ直れば、片方だけ覚めます

## 登録

`~/.claude/settings.json`（またはプロジェクトの `.claude/settings.json`）に置きます。
**先にバックアップを取ってください。**

```json
{
  "hooks": {
    "PreCompact": [
      { "hooks": [ { "type": "command", "timeout": 60,
        "command": "python \"<repo>/infracubus/infracubus.py\" --repo \"<repo>\"" } ] }
    ],
    "SessionEnd": [
      { "hooks": [ { "type": "command", "timeout": 60,
        "command": "python \"<repo>/infracubus/infracubus.py\" --repo \"<repo>\"" } ] }
    ]
  }
}
```

`--cwd` は要りません。**hook が stdin で `cwd` を渡してくれる**ので、
どのプロジェクトの記憶置き場に書くかは自動で決まります。`hook_event_name` も
届くので、どの眠りで見た夢かも残ります。

手で確かめるときは `--wake`（結果を表示）か `--dry-run`（走らせるが書かない）を付けます。

```
python infracubus/infracubus.py --repo . --wake
```

詳細は [docs/hook-registration.md](docs/hook-registration.md) にあります。

## 測って分かったこと

### `doctor.py` は stderr に何も出しません

**ここが設計の分かれ目でした。**当初は「stderr にエラーが出たら」で考えていましたが、
実測すると **stderr は 0 行**です。

```
exit code = 1
--- stderr（0 行）---
```

全部 stdout に `[ok]` / `[error]` の行として出ます。**stderr を見張る作りだと、
永久に何も起きません。**判定は exit code、中身は stdout から拾っています。

### 名前と本文の切り方

`doctor.py` の出力は `[status] name: detail` ですが、**name 自体がコロンを含みます**
（`config:file`、`state:C:\Users\...`）。ただし name の中のコロンには空白が続かないので、
**コロン+スペースの最初の出現**で切れば正しく分かれます。

### 0.11 秒でした

`PreCompact` は「一番忙しい瞬間」なので遅延を心配しましたが、手元では 3 回とも
**0.10〜0.11 秒**でした。眠りは遅くなりません。

ただしこれは `.mcp.json` が無くて MCP live probe まで到達しない状態での値です。
**probe が走る環境ではもっとかかります。**`timeout` を付けておくことを勧めます。

### 落ちないようにしてあります

眠りに憑いている以上、**ここで例外を投げても誰も気づけません。**
`doctor.py` が無い・走らない・タイムアウトした場合は stderr に一言だけ残して
終了コード 0 で戻ります。**黙って寝るほうが、嘘の安心より害が少ない**と考えました。

hook からの JSON が壊れていた場合も同様ですが、こちらは黙ると
**間違った置き場に夢を書きうる**ので、警告を出します。

### Windows では encoding を明示しないと落ちます

タスク配下では locale が cp932 になり、`doctor.py` の出力が化けます。化けるだけなら
まだしも、**読み取り側が例外で落ちると夢を見ないまま朝になります。**
子プロセスに `PYTHONIOENCODING=utf-8` を渡し、読み取りは `errors="replace"` に
してあります。ファイルの読み書きも全て `encoding="utf-8"` を明示しています。

## やらなかったこと

- **`memory.db` の中身は診ません。**試作では「consolidation が走った形跡があるか」
  「記憶が読まれているか」まで測っていましたが、**風呂敷を広げすぎでした。**
  Infracubus は `doctor.py` 一本に絞ります
- **S.M.A.R.T. などは取りません。**lifemate-ai はマルチプラットフォームなので、
  環境依存のものを持ち込みません
- **`doctor.py` 自身は直しません。**このスクリプトは `doctor.py` を呼ぶ側です

## 制約

- **`MEMORY.md` の `<!-- infracubus:begin -->` 〜 `<!-- infracubus:end -->` の間だけ**を
  書き換えます。他の行には触りません。ただし**その区画の中に手で書いたものは消えます**
- 記憶置き場の探索は `~/.claude/projects/<平坦化したパス>/memory/` を見ています。
  **この規則は公開仕様ではない**ので、既存ディレクトリを優先し、推測は最後の手段にしています
- 台帳は `~/.claude/infracubus/dreams.json` です。`INFRACUBUS_STATE` で移せます
- 依存は**標準ライブラリだけ**です。眠りに憑くものが重い依存を持つと、眠りが遅くなります

## これは夢であって事実ではありません

書き出す各ファイルの末尾に、こう入れてあります。

> これは Infracubus が眠りの中で書いたもの。書いた瞬間を誰も体験していない。
> **起きている自分が確かめるまで、これは夢であって事実ではない。**

`doctor.py` の判定が正しいとは限りませんし、`×5夜` は「5 日直していない」であって
「5 日壊れている」とは限りません。**目覚めた側が確かめてから動くべきもの**として
書いています。
